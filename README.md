# KAZ KOMPOZIT — B2B-платформа продажи стеклокомпозитной арматуры

Сайт + каталог + калькулятор + заявки и CRM + админка + КП в PDF + WhatsApp-бот + ИИ-агенты.
Языки сайта: русский (`/ru`) и казахский (`/kk`).

## Что внутри

| Часть | Технологии |
|---|---|
| Сайт и админка | Next.js 15 (App Router), TypeScript, Tailwind CSS |
| База данных | PostgreSQL, Drizzle ORM, миграции в папке `drizzle/` |
| Деньги | `decimal.js` — точная десятичная арифметика, без float и без ИИ |
| PDF | PDFKit на сервере, шрифт DejaVu (кириллица и казахские буквы) |
| Файлы | S3-совместимое хранилище или локальная папка |
| Авторизация | JWT в httpOnly-cookie, bcrypt, роли и журнал действий |

## Правила, заложенные в код

- **Закупочные цены** лежат в отдельной таблице `purchase_prices`. Публичный слой
  (`src/server/public/*`) её не импортирует; автотест `tests/security.test.ts` это проверяет.
  В журнал пишется только факт изменения, без сумм.
- **Цены на сайте**: утверждённая — видна всем; демо — только при `APP_MODE=test` и с пометкой;
  иначе «Цена по запросу».
- **Стоимость пересчитывается на сервере** при каждой заявке — данным из браузера не доверяем.
- **Доставка**: пока тариф города не подтверждён, клиент видит «Доставка рассчитывается менеджером»,
  итоговая сумма не показывается.
- **КП**: черновик → утверждение (админ/менеджер) → отправка. Отправить черновик нельзя.
- **ИИ-агенты** работают только через инструменты из `src/agents/tools.ts`. Запись цен в сделку —
  через очередь подтверждения. Деньги считает код. Массовых рассылок нет.
- Характеристики, масса и длины бухт в начальных данных помечены как **неподтверждённые**
  и показываются на сайте с пометкой, пока вы их не подтвердите в админке.

## Быстрый старт локально

Нужны Node.js 20+ и PostgreSQL 14+.

```bash
cp .env.example .env          # впишите DATABASE_URL, AUTH_SECRET, ADMIN_PASSWORD
docker compose up -d          # если PostgreSQL нет — поднимет его в Docker
npm install
npm run db:migrate            # создать таблицы
npm run db:seed               # товары 6/8/10/12 мм, города, FAQ, администратор
npm run dev                   # http://localhost:3000, админка — /admin
```

На Windows можно просто запустить `start-windows.bat` — он сделает всё по шагам.

Проверки: `npm run typecheck`, `npm test`, `npm run build`.

## Развёртывание на Railway

1. Загрузите проект в репозиторий GitHub.
2. В Railway: **New Project → Deploy from GitHub repo**, затем **+ New → Database → PostgreSQL**.
3. В сервисе сайта задайте переменные:
   - `DATABASE_URL` = `${{Postgres.DATABASE_URL}}`
   - `AUTH_SECRET` — случайная строка 32+ символов
   - `SITE_URL` — адрес сайта, например `https://kazkompozit.kz`
   - `APP_MODE` = `test` (после утверждения цен — `production`)
   - `ADMIN_EMAIL`, `ADMIN_PASSWORD`
4. Файлы (фото, сертификаты, спецификации): либо **Volume** с путём монтирования `/app/storage`
   и `STORAGE_DIR=/app/storage`, либо **Bucket** Railway и переменные `S3_*`.
5. Деплой: Railway выполнит `npm run build`, при старте — миграции, начальные данные и запуск.
   Проверка здоровья — `/api/health`.

Резервное копирование: включите бэкапы сервиса PostgreSQL в Railway (Backups) и/или
выполняйте `pg_dump "$DATABASE_URL" > backup.sql` по расписанию.
Мониторинг ошибок: логи сервиса в Railway; для внешнего мониторинга можно подключить Sentry.

## Внешние сервисы — статус

| Сервис | Статус | Как подключить |
|---|---|---|
| WhatsApp Business Platform | **Не подключено**, работает тестовая консоль в админке | `WHATSAPP_TOKEN`, `WHATSAPP_PHONE_NUMBER_ID`, `WHATSAPP_VERIFY_TOKEN`, `WHATSAPP_APP_SECRET`; вебхук `SITE_URL/api/whatsapp/webhook` |
| Языковая модель для агентов | **Не подключено**, агенты работают на шаблонах | `LLM_API_KEY`, `LLM_MODEL` (+ `LLM_PROVIDER=openai-compatible`, `LLM_BASE_URL`) |
| Уведомления в Telegram | **Не подключено**, заявки видны в админке | `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` |
| S3-хранилище | Не подключено, используется локальная папка | переменные `S3_*` |
| Онлайн-оплата | Не реализована намеренно | подключается позже |

## Что заполнить перед запуском в работу

1. **Настройки компании**: телефон, WhatsApp, e-mail, адрес (отметить «подтверждён»), ссылка на карту.
2. **Розничные и оптовые цены**: вписать и отметить «Утверждена», затем `APP_MODE=production`.
3. **Товары**: реальные фото, подтверждённые характеристики, масса, длины бухт и прутков.
4. **Поставщики** и **закупочные цены** — актуализировать.
5. **Логистика**: тарифы городов по мере подтверждения, проверенные транспортные партнёры.
6. **Сертификаты** — только подлинные документы.
7. Демо-скидки за объём («Демо: опт от 2 000 м» и т. п.) — изменить или отключить.
